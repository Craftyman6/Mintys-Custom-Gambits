# Minty's Mods and Custom Gambits
Mods for Gambonanza that are added to the game through the usage of the [Gambonanza Mod Manager](https://bentrd.github.io/GambonanzaMods/).
## Tile Console
Registers a command named "tile" to the console. This command
is to be used to modify/color/crumble a tile. This can also be
applied to a whole row/column of tiles, or even every tile on
the board.

**Turf War's Gambit:** Pieces paint tiles their respective color, splashing into adjacent tiles on capture. Earn $1 per 5 white tiles at end of game
